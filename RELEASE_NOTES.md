# SeeXmind 0.3.0

- Preview `.xmind` files, embed maps in notes and switch sheets on iPhone, iPad and Android, alongside macOS and Windows.
- Pan with one finger and zoom with a two-finger pinch. Touch controls are at least 44 px; tap the canvas to reveal them for 3.5 seconds, including at 0% idle opacity.
- Use **Open / share** on mobile and choose Xmind through the system. Opening may import a copy; save back or replace the vault file after editing to update Obsidian. If needed, open the file through the system Files app or Xmind's **Open from Files**.
- Keep desktop double-click opening and custom macOS `.app` / Windows `.exe` paths. The disclosed Shell Execution capability applies to desktop opening; mobile uses Obsidian's native file handoff.
- Existing custom paths and idle opacity are preserved. Download `main.js`, `manifest.json` and `styles.css` from this release into `.obsidian/plugins/seexmind/`, preserving `data.json` when updating.
