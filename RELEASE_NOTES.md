# SeeXmind 0.2.0

- Embed maps in notes using `![[Map.xmind]]`, with independent zoom and sheet selection.
- Switch sheets with local structure previews; retain embedded image mode for original appearance. Structure layout may differ from Xmind and does not reconstruct all advanced elements or resource images.
- English and Simplified Chinese interface following Obsidian's language.
- Floating right-side controls and bottom-right Open in Xmind, with configurable 0–100% idle opacity.
- Download the three attached files and place them in `.obsidian/plugins/seexmind/`; preserve `data.json` when updating.
