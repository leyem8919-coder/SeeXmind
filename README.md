# SeeXmind

**在 Obsidian 中预览，在 Xmind 中编辑。**

SeeXmind 是一款面向 macOS 和 Windows 桌面版 Obsidian 的轻量插件，让 `.xmind` 文件融入笔记库的浏览流程。

## 两个核心操作

| 操作 | 效果 |
| --- | --- |
| 单击左侧文件目录中的 `.xmind` | 在右侧内容区显示文件内置预览 |
| 双击 `.xmind` | 使用本机 Xmind 打开原文件进行编辑 |

预览支持缩放、拖动平移和适应窗口。文件保存并同步到本地后，插件检测变化并刷新预览，也可以手动刷新。

## 保留原有画面

SeeXmind 读取 `.xmind` 文件内部的 `Thumbnails/thumbnail.png`，直接显示文件自带的图片。每份文件读取自己的预览，不需要另行管理图片或匹配文件名。

插件不重新计算节点布局、字体、颜色或连接线，因此不会因重新排版而改变内置预览的外观。Mac 和 Windows 使用相同的读取方式，无须依赖 macOS 的系统预览功能。

## 本地使用

- 预览在本机完成，无须注册账号或连接预览服务器。
- 不上传导图，不包含遥测。
- 插件只读取文件；编辑交给本机安装的 Xmind。
- Windows 默认通过 `.xmind` 的系统文件关联打开，请将默认应用设置为 Xmind；也可指定 Xmind 程序路径。

## 适用范围与限制

- 面向 macOS 和 Windows 的 Obsidian 桌面版，暂不支持移动端。
- 当前是图片预览，不是嵌入式 Xmind 编辑器。
- 清晰度取决于文件内置图片的分辨率，放大后可能模糊。
- 多画布文件的内置图片可能只包含其中一个画布。
- 没有内置预览、加密或损坏的文件会显示提示，需要在 Xmind 中打开处理。
- 预览反映已保存的图片；Xmind 未保存或跨设备同步未完成时，可能仍显示旧内容。
